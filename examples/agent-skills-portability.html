Decision under pressure

Can one Agent Skill work across Claude Code, Codex, GitHub Copilot, Cursor, and Gemini CLI without client-specific forks?

Author one conservative Agent Skills core, but install and test it per host. SKILL.md, references, assets, and scripts are portable; discovery paths, invocation, consent, permissions, metadata, and distribution are not behaviorally identical.

Reasoning edges

  1. The standard supplies a deliberately small package contract that clients can share.

  2. Claude Code explicitly identifies its skills as an implementation of the open standard.

  3. Codex documents the same SKILL.md authoring model and progressive loading pattern.

  4. Copilot adopts the standard across several GitHub and IDE surfaces.

  5. Cursor reads SKILL.md packages in both its editor and CLI.

  6. Gemini CLI implements the same directory-plus-SKILL.md package shape.

  7. Claude's native .claude locations and cloud-session rules are host-specific.

  8. Codex scans .agents locations across working-directory and repository scopes.

  9. Copilot accepts several compatibility paths, but its supported scopes and surfaces remain product-defined.

  10. Gemini uses a native .gemini path while accepting .agents as an alias.

  11. Claude adds invocation control, subagent execution, dynamic context, and permission fields.

  12. Codex adds initial-list context budgets, OpenAI metadata, and plugin distribution guidance.

  13. Cursor defines its own automatic and slash-menu activation surfaces.

  14. Gemini inserts an explicit consent step before a discovered skill activates.

  15. A shared file format does not create one universal installation or discovery location.

  16. Portable instructions can still activate, execute, and persist differently across hosts.

  17. One canonical payload avoids maintaining five independent instruction bodies.

  18. Thin generated mirrors handle path differences without forking the workflow.

  19. Per-host acceptance tests are necessary when behavior is not standardized.

  20. The shared minimum makes author-once a defensible default.

  21. Canonical content plus thin adapters preserves portability without pretending the clients are identical.

  22. Equivalent behavior remains an unverified hypothesis until one shared suite exercises all five clients.
