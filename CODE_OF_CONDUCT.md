# Code of Conduct

We want Doubt to be skeptical of claims, not hostile to people.

Be respectful, argue from evidence, make room for correction, and assume good intent while still
protecting the project and its users. Harassment, discrimination, threats, doxxing, and sustained
bad-faith disruption are not accepted.

Report conduct concerns privately to the maintainer through the security contact listed in
[SECURITY.md](SECURITY.md). Project maintainers may remove, edit, or reject contributions and
participation that violate these expectations.
